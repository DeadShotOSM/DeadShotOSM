# OSM — Osmanlı Tugayı

Rainbow Six Siege için hazırlanmış statik e-spor takım sitesi.

## GitHub Pages'e yayınlama

1. GitHub'da yeni bir repository oluştur: örneğin `osm-esports`.
2. Bu klasördeki tüm dosyaları repository'nin ana dizinine yükle.
3. **Settings → Pages** bölümüne gir.
4. **Deploy from a branch** seç.
5. Branch olarak `main`, klasör olarak `/ (root)` seç ve kaydet.
6. GitHub birkaç dakika içinde sitenin adresini oluşturur.

## Özelleştirme

- Oyuncu isimleri: `index.html`
- Maç/başarı bilgileri: `index.html`
- Renkler ve tasarım: `style.css`
- Takım logosu: `assets/logo.png`
- Discord / YouTube / Twitch bağlantıları: `index.html` içindeki `#` bağlantıları
